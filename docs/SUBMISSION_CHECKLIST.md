# VANTA Theme Store submission checklist

## Completed in repository

- [x] Locally actionable audit failures fixed.
- [x] Theme Check and structural tests pass.
- [x] Core commerce/search/contact/blog/cart/browser checks pass.
- [x] Requested responsive viewport matrix passes.
- [x] JavaScript-disabled navigation, variants and add-to-cart pass.
- [x] Accessibility, reduced-motion and WebGL fallback/lifecycle automation pass.
- [x] Lighthouse averages exceed Shopify's minimums.
- [x] Assets are optimized, licenses/provenance recorded and development artifacts excluded.
- [x] `config/markets.json` is absent; a single preset means `/listings` is not required.
- [x] Draft theme updated without publishing.
- [x] Final ZIP metadata and SHA-256 recorded after package inspection.

## Manual owner / Partner Dashboard actions

- [ ] Confirm `VANTA` is legally usable, distinct from the Partner company name, and acceptable as both theme and preset name.
- [ ] Confirm Theme Store exclusivity and all code, model, font, icon and image rights.
- [ ] Confirm the public documentation URL remains available and the public support workflow satisfies Shopify support obligations.
- [ ] Confirm an eligible Partner account and client transfer demo store using the final theme version.
- [ ] Add benchmark products/data for gift-card recipient, unit price, pickup, Shop Pay Installments, sale/sold-out, video, model, swatches and article comments; manually verify each populated state.
- [ ] Configure markets, languages, policies, payment methods and test mode; complete a Shopify test order/refund rather than a real charge.
- [ ] Smoke-test section add/remove/reorder/select/deselect in the authenticated Theme Editor.
- [ ] Test current physical iOS Safari, Android Chrome/webview, desktop Safari/Chrome/Firefox/Edge and at least one screen reader.
- [ ] Capture listing screenshots without browser/editor chrome: desktop 1000×1248 or 2000×2496; mobile 750×1334; add accurate alt text.
- [ ] Prepare accurate listing copy, features, price, demo-store URL and support information.
- [ ] Upload the verified ZIP and submit it in Shopify Partner Dashboard. Do not publish the draft storefront as part of this repository workflow.

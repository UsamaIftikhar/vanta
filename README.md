# VANTA

Original native Shopify theme in development: editorial commerce, configurable sections, progressive motion and optional fault-tolerant WebGL.

```sh
npm ci
npm run build
npm run check
npm test
npm run dev -- --store your-store.myshopify.com
```

Then run `npm run test:browser` against the local Shopify preview. See [development](docs/DEVELOPMENT.md), [merchant guide](docs/MERCHANT_GUIDE.md), [implementation status](docs/IMPLEMENTATION_STATUS.md) and [submission audit](docs/THEME_STORE_SUBMISSION.md).

**Not Theme Store-approved or release-ready.** Live-device, complete catalog, real 3D, benchmark and business/support gates remain documented. Original fictional demo images are included; product media uses genuine Shopify data.
